# Restrospective

## What Went Well?
Overall, the majority of the project went well. To be specific, actually creating the pages and using HTML went wonderfully. I truly found ease and repitition in writing the code which made fixing mistakes much easier. Formatting the documentation and files also went well and is organized.

## What Went Wrong?
A lot more went wrong during this project than I anticipated. I got off track of my schedule because I got called into work a few times, so that put a small bump in the road. On top of that, I was having trouble correctly coding my external stylesheet and had to do multiple commits to fix things. My computer is also somewhat slow and was taking forever to refresh Github so I could actually view my changes.

## What Would I Do Differently?
I would definitely allot more time and use whatever random time I get throughout the day to work on my project. I would also choose my color scheme and work on a stylesheet as its own task as it is a lot, especially combined with other aspects of the project. Overall, I would work to better manage my time and learn more nuance aspects of CSS to better my styling.
