# Project Purpose: To create a multi-page functional website explaining the basics of fishing for catfish, or catfishing, and to provide myself with a fundamental knowledge of HTML and CSS styling.
## Project Description: This site will include a detailed description on the best techniques, gear, and bait to use when fishing for catfish. I will use <p> elements for paragraphs, <li> elements for ordered lists, <ul> for unordered lists, <br> for line breaks, as well as different <h> element levels. I will use a CSS styling sheet across both pages to maintain consistency.
## Desired Results: The measurable outcomes for this project will be a multi-page, public repository and website about catfishing. This website will have 2 pages, 'index.html' and 'about.html.' The former will be the home page including information about catfishing, the latter will be an page about myself. There will be navigation from one screen to another through hyperlinks. I will then be able to submit the projects in hopes of getting an excellent grade. I also hope to help educate a few more fisherman about the best ways to catfish
## Exclusions: I will only focus on the best catfishing techniques in Texas, as they may not be applicable to other states with different water conditions. Using these techniques does not guarantee a bite, rather, it helps your odds. This website will NOT include Javascript or inline styling. There will be no interactive features, videos, or contact forms included. It also will NOT include any information pertaining to types of fishing besides catfishing.
## Acceptance Criteria: This project can be accepted once 'index.html,' 'about.html,' 'docs/,' are compiled and my repository and website URLs are live and public
